Objectif livré : rendre CorvusRepository propriétaire autonome des mises à jour de cœurs et permettre les fournisseurs tiers approuvés, sans nouveau build APK.
Budget DEEP : distribution de code natif, provenance/CI, publication GitHub immuable, compatibilité avec le client existant. Agents distincts compilation officielle, import communautaire, séparation frontend, revue et qualification Android autorisés par develop.
Invariants : format3/API0, ID permanents, catalogue central relu, hébergement central approuvé, base sans cœur, licences fournisseurs, anciens assets conservés, aucun secret APK requis côté Repository.
Étapes accomplies : outils/registre/workflows séparant lecture et publication ; 53 tests et six vrais builds NDK ; revue et PR/CI/fusion ; simulation Actions ; publication autonome de six nouveaux ZIP dans le lot v0.15.1, sans modifier les archives historiques ; vérification des octets publics puis PR de catalogue et CI/fusion ; frontend APK seulement qualifié et fusionné ; essais Android et documentation finale.
P0 couverts : origines/provenances/CI/archives invalides, traversal/symlink/limites ZIP/ABI/export/runtime/16Ko, simulation sans mutation GitHub, protection des assets, promotion seulement après téléchargements publics, revue et CI explicite.
P1 couverts : six ELF sans frontend, Gradle Debug/Release/lint et signature durable ; client0.18 compatible, catalogue public et CI exacte ; GB/GBC/GBA paysage sur les vrais modules publics, 385 contrôles.
Les preuves, limites et décisions finales figurent dans progress.md et quality.md. Chaque futur fournisseur est soumis à revue de licence/source et à ses propres tests, avant sa première publication.
